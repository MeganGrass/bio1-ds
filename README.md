## About
- The main executables and all overlays are completely decompiled and byte-matching.

## Build
- Sony PlayStation SDK (aka PSY-Q) is required
- manually set `tools\sdkroot.ini` with local PSY-Q SDK paths

### Windows
- run setup.bat to build the custom SDK and required compiler (gcc-2.6.3-psx)
- run build.bat to build the executable. alternatively, build with provided Visual Studio solution
